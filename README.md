# Jdunn596 Tap

## How do I install these formulae?

`brew install jdunn596/tap/<formula>`

Or `brew tap jdunn596/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jdunn596/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
